# مستمسكاتي — Mostamskaty

برنامج لإعداد صور المستمسكات العراقية وقصها وتحسينها وترتيبها على ورق A4 بالمقاسات الفعلية. يتوفر كنسخة ويندوز محلية ونسخة متصفح قابلة للاستضافة مجانًا.

## الخيار المجاني: نسخة الويب على Streamlit Community Cloud

لا تحتاج هذه الطريقة إلى Codespaces أو تثبيت Python على جهازك. الكود جاهز للنشر؛ إنشاء الحساب وربطه بـ GitHub والضغط على النشر تتم من حسابك.

1. افتح https://share.streamlit.io/ وسجّل الدخول بحساب GitHub. اختر **Streamlit Community Cloud** المجانية، وليس خطة مدفوعة أو تجربة Snowflake.
2. اضغط **Create app**، ثم اختر النشر من مستودع GitHub.
3. حدّد المستودع **`hasanwadhah/Mostamskaty-`** والفرع **`main`**.
4. في **Main file path** اكتب بالضبط: **`web/streamlit_app.py`**.
5. من **Advanced settings** اختر **Python 3.12**، ثم اضغط **Deploy**.
6. بعد اكتمال التثبيت ستحصل على رابط التطبيق الذي تفتحه من المتصفح. لا تحتاج إلى كلمة مرور سطح المكتب أو المنفذ 6080.

تثبّت الخدمة مكتبات نسخة الويب من `web/requirements.txt`، واعتماديات النظام من `packages.txt`. لا توجد مفاتيح API أو أسرار مطلوبة. الخدمة لها حدود موارد وقد تدخل التطبيقات غير المستخدمة في وضع السكون؛ ليس مطلوبًا شراء Codespaces لتشغيل هذه النسخة. الاستضافة الفعلية تعتمد على حسابك وإتاحة الخطة المجانية لدى Streamlit.

تتوفر أربع بطاقات، ورفع الوجه والظهر، ومحرر بأربع زوايا قابلة للسحب، وتصحيح المنظور والتحسين والتدوير والميلان، ومعاينة A4، وتصدير PDF وPNG/JPG بدقة 300 أو 600 dpi. صور الصفحات المتعددة تُجمع في ZIP. الطباعة من المتصفح تتم بتنزيل PDF ثم طباعته بالحجم الفعلي 100%.

لملاءمة موارد الاستضافة المجانية، حجم الرفع الأقصى 12 MB للصورة، وتُستخدم نسخة بحد أقصى 2200 بكسل للضلع الأطول. الكشف يستخدم OpenCV دون تحميل U2-Net على خادم الويب. رفع دقة التصدير إلى 600 dpi لا يضيف تفاصيل غير موجودة في الصورة الأصلية. تبقى نسخة ويندوز بكامل إعداداتها والنموذج المحلي الاختياري متاحة أدناه.

**خصوصية نسخة الويب:** الصور تُرفع إلى جهاز Streamlit السحابي لمعالجتها في جلستك. لا يضيف البرنامج قاعدة بيانات أو سجل مستمسكات. زر «مسح الجلسة بالكامل» يزيل الصور والنتائج من حالة التطبيق الحالية. للصور التي تريد إبقاءها على جهازك استخدم نسخة ويندوز المحلية، والتزم بشروط وسياسة الاستضافة عند استخدام الخدمة السحابية.

تشغيل نسخة الويب محليًا للتطوير:

```bash
.venv/bin/python -m pip install -r web/requirements.txt
.venv/bin/python -m streamlit run web/streamlit_app.py
```

## التشغيل من GitHub داخل المتصفح دون تثبيت على جهازك

[Codespaces خيار منفصل](https://github.com/features/codespaces) يخضع لحصة حسابك وقد يطلب دفعًا؛ استخدم خيار Streamlit أعلاه إذا أردت الاستضافة المجانية بدل سطح المكتب البعيد.

[افتح المشروع في GitHub Codespaces](https://codespaces.new/hasanwadhah/Mostamskaty-?ref=main)، ثم اضغط **Create codespace** وانتظر اكتمال بناء البيئة والتثبيت. الحساب يحتاج إتاحة Codespaces وحصة استخدام؛ أوقف الجلسة عند الانتهاء.

في الطرفية **Terminal** داخل Codespaces، اكتب:

```bash
bash run.sh
```

افتح تبويب **Ports**، وابحث عن المنفذ **6080 — Mostamskaty Desktop**، ثم اضغط أيقونة الكرة الأرضية **Open in Browser**. اضغط **Connect** واكتب كلمة مرور سطح المكتب الافتراضية **`vscode`**. ستظهر نافذة البرنامج داخل سطح المكتب في المتصفح. احتفظ بظهور المنفذ **Private**؛ جلسة Codespaces ليست رابطًا عامًا للمشاركة.

إذا كان لديك Codespace أُنشئ قبل إضافة هذه الإعدادات، نفّذ `git pull origin main`، ثم من لوحة الأوامر **Ctrl+Shift+P** اختر **Codespaces: Rebuild Container** وانتظر انتهاء الإعداد، وبعدها نفّذ `bash run.sh`. عند فشل تثبيت المكتبات بسبب انقطاع اتصال عابر، يمكن إعادة `bash scripts/setup_codespaces.sh`.

لرفع صور من جهازك، اسحبها إلى مستكشف الملفات في Codespaces، ثم اخترها من نافذة رفع الوجه أو الظهر داخل البرنامج. صدّر النتيجة إلى مجلد المشروع، ثم اضغط بزر الفأرة الأيمن على ملف PDF في مستكشف Codespaces واختر **Download**. الطابعة المتصلة بجهازك غير متصلة بسطح المكتب السحابي؛ اطبع PDF الذي نزّلته بالحجم الفعلي 100%.

هذا تشغيل بعيد للتطبيق المكتبي، وليس نسخة ويب مستقلة. الصور التي ترفعها هنا تُعالَج داخل جهاز Codespaces السحابي وتحتاج اتصال إنترنت للوصول إلى الجلسة. للعمل محليًا دون اتصال، استخدم طريقة ويندوز أدناه. احذف صورك وملفات التصدير من Codespace بعد الانتهاء.

اختياريًا لتفعيل U2-Net داخل Codespaces، نفّذ مرة واحدة:

```bash
.venv/bin/python -m pip install -r requirements-ai.txt
.venv/bin/python download_model.py
```

## التشغيل على ويندوز

1. ثبّت **Python 3.12 x64** من https://www.python.org/downloads/ مع Python Launcher، أو أضف Python إلى PATH.
2. نزّل ملفات هذا المشروع معًا، ثم شغّل `install_windows.bat` مرة واحدة. التثبيت الأول يحتاج إنترنت.
3. شغّل `run_windows.bat` لفتح البرنامج.
4. اختياريًا، شغّل `install_ai_windows.bat` مرة واحدة لتثبيت rembg وتحميل نموذج U2-Net الرسمي (~176 MB). بعد التثبيت يعمل النموذج دون إنترنت.

يمكن كذلك تشغيل الملف الرئيسي وحده بعد تثبيت المكتبات:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe iraqi_id_printer.py
```

ملف البرنامج الرئيسي هو `iraqi_id_printer.py`؛ لا يعتمد على صور أو ملفات واجهة خارجية. ملفات المتطلبات والتشغيل لتسهيل التثبيت.

## الاستخدام

- اختر نوع المستمسك، ثم ارفع الوجه أو الظهر في إحدى البطاقات الأربع.
- تفتح نافذة القص ويعمل الكشف المحلي تلقائيًا. راجع الزوايا الأربع، خصوصًا عند وجود يد أو خلفية مزدحمة. حرّك المقابض الخضراء إلى حواف المستمسك؛ عجلة الفأرة تكبّر وتصغّر، وسحب الخلفية يحرّك الصورة.
- **تطبيق القص** يصحح المنظور. **تحسين الألوان** يتنقل بين ماسح ملون، أبيض وأسود، وألوان ما قبل التحسين. التحسين يحسن التباين والحدة؛ لا يستعيد معلومات محروقة بالضوء أو غير موجودة في الأصل.
- يمكن ضبط الميلان والتدوير وإضافة حافة أو استعادة الأصل. اعتماد الصورة يطبق القص تلقائيًا إن لم يُطبّق مسبقًا. إلغاء النافذة لا يستبدل الصورة الموجودة.
- عدّل التباعد بالملليمتر، أو مقاس كل بطاقة بالسنتيمتر. يظهر الوجه يمين الظهر عند اتساع الصف لكليهما؛ الوجه المنفرد يُوسّط.
- الوثائق الكبيرة تُرتّب عموديًا، وتُنشأ صفحات إضافية عند الحاجة **دون تصغير المقاس الفعلي**. إذا تجاوزت وثيقة واحدة مساحة A4 بهامش 10 مم، يمنع البرنامج التصدير حتى تُصحح الأبعاد.
- اختر 300 أو 600 dpi، ثم صدّر PDF أو PNG/JPG أو اطبع مباشرة. تصدير الصور يشمل جميع الصفحات، بأسماء مرقمة عند تعددها، مثل `هويات_01.png`.
- عند الطباعة من قارئ PDF خارجي، اختر **الحجم الفعلي / Actual Size / 100%** وألغِ Fit to Page. الطباعة المباشرة تستخدم A4 عموديًا وإحداثيات فعلية بالملليمتر. اختبر نسخة أولى بمسطرة، فتعريف الطابعة وإعداداته قد يؤثران في النتيجة الورقية.

## المقاسات الافتراضية

هذه مقاسات العمل المطلوبة في المواصفات، ويمكن تعديلها حسب المستمسك الموجود:

| النوع | العرض × الارتفاع |
| --- | --- |
| الوطنية، السكن، التموينية الإلكترونية، الناخب، كي كارد / ماستر كارد | 8.6 × 5.6 سم |
| هوية الأحوال المدنية القديمة | 6.5 × 9.5 سم |
| شهادة الجنسية العراقية | 13 × 18 سم |
| جواز السفر العراقي | 12.5 × 8.8 سم |

صفحة A4 تساوي 210 × 297 مم. دقة 300 dpi تنتج 2480 × 3508 بكسل، ودقة 600 dpi تنتج 4961 × 7016 بكسل بعد التقريب لأقرب بكسل. PDF يحفظ المقاسات بوحدات فعلية مستقلة عن تقريب البكسلات. المعاينة الخفيفة 96 dpi؛ هذا لا يغيّر دقة التصدير.

تغيير نسبة أبعاد بطاقة بعد القص يحافظ على نسبة الصورة ويضيف مساحة بيضاء عند الحاجة، بدل تشويه النص. للحصول على صورة تملأ المقاس الجديد، أعد رفعها وقصها بالنسبة المطلوبة.

## النموذج المحلي والخصوصية

لا يستخدم التطبيق API أو مفاتيح وصول، ولا يحاول تنزيل نموذج أثناء فتح الصور. يبحث عن `u2net.onnx` بهذا الترتيب:

1. المجلد المشار إليه بمتغير `U2NET_HOME` إذا كان مضبوطًا.
2. `models/u2net.onnx` بجوار الملف الرئيسي.
3. مجلد المستخدم `~/.u2net/u2net.onnx`.

تحضير النموذج صراحةً، قبل الانتقال إلى العمل دون اتصال:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-ai.txt
.venv\Scripts\python.exe download_model.py
```

المصدر الرسمي: https://github.com/danielgatis/rembg/releases/download/v0.0.0/u2net.onnx

بصمة MD5 المنشورة في rembg، والتي يتحقق منها التنزيل والتطبيق: `60024c5c889badc19c04ad937298a77b`.

إذا غاب rembg أو النموذج أو فشل التحقق منه، يستمر كشف الحواف بـ OpenCV مع توضيح ذلك في نافذة التحرير. U2-Net يجزّئ المقدمة عمومًا؛ ليس نموذجًا مدرّبًا خصيصًا للتعرف على الهويات العراقية. لذلك يجب مراجعة الزوايا في الصور الواقعية، ولا يُضمن الفصل الصحيح عن الأيدي والخلفيات المعقدة.

الصور تبقى في ذاكرة الجلسة ولا تُرفع أو تُحفظ تلقائيًا. تُكتب فقط الملفات التي تختار تصديرها. الجلسة لا تُستعاد بعد إغلاق التطبيق؛ صدّر النتيجة أولًا. لا تُضاف علامة المطور إلى المستمسكات المطبوعة؛ الاسم والحقوق في الواجهة وبيانات PDF.

## لينكس وبيئة التطوير السحابية

```bash
cd /workspace/Mostamskaty-
python -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python iraqi_id_printer.py
```

يلزم سطح مكتب رسومي لفتح النوافذ تفاعليًا، وطابعة مضافة لنظام التشغيل للطباعة الورقية. في البيئة السحابية دون شاشة، اختبر الواجهة ومحرك الطباعة دون نافذة:

```bash
QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q
```

لاختبار الويب في متصفح فعلي، بعد تشغيل Streamlit في طرفية أخرى، ثبّت Playwright ثم شغّل الفحص. يستخدم صورًا اصطناعية ويختبر رفع الوجه والظهر، سحب الزوايا، القص، تنزيل PDF ومسح الجلسة:

```bash
.venv/bin/python -m pip install playwright==1.58.0
.venv/bin/python -m playwright install chromium
.venv/bin/python scripts/smoke_web.py
```

إذا كان Chromium مثبتًا على النظام يستخدمه الفحص تلقائيًا. يمكن ضبط مساره عبر `CHROMIUM_EXECUTABLE` وعنوان الخادم عبر `MOSTAMSKATY_URL`. ملفات الفحص الناتجة في `artifacts/` المتجاهل من Git.

التثبيت يستخدم `opencv-python-headless` لتوفير cv2 نفسه دون إضافات Qt المتعارضة مع PyQt5؛ الواجهة الرسومية تأتي من PyQt5. لا تثبّت نسختي OpenCV معًا. إذا افتقد لينكس مكتبات عرض النظام، ثبّت اعتماديات Qt/X11 الموصى بها لتوزيعتك، أو استخدم `offscreen` للاختبارات فقط.

تغطي الاختبارات: تصحيح المنظور، صورًا اصطناعية، المسارات العربية وEXIF والشفافية، التحسين والميلان، ترتيب الوجه والظهر، الترحيل بين الصفحات، مقاسات PDF والصور وبيانات الدقة، تعامل الواجهة مع القص والإخفاق، ومسار QPrinter إلى PDF. لا تحل محل اختبار طابعة فعلية أو تقييم صور مستمسكات حقيقية متنوعة.
